# robots.txt for torin.bg
#
# This file and sitemap.xml did not exist on this site before Phase 4 -- both
# returned 404 on the live origin. Neither is a migrated file.
#
# NOTHING IS DISALLOWED HERE, AND THAT IS DELIBERATE.
#  - A Disallow is not an access control. It is a PUBLIC LIST of paths worth
#    looking at, readable by anyone. src/includes/ and src/vendor/ are protected
#    by being un-linked and by .htaccess denying the sensitive files outright
#    (settings.txt, .user.ini, php-fcgi); naming them here would advertise them
#    and protect nothing.
#  - msg.html is NOT disallowed even though it must not be indexed. It carries
#    <meta name="robots" content="noindex, follow"> instead. Disallowing it would
#    stop the crawler FETCHING it, so the noindex would never be read, and the
#    URL could still be indexed bare from an external link -- the exact opposite
#    of the intent. It is also absent from sitemap.xml, which is the other half
#    of the same instruction.
#  - contact-send.php needs no rule: it answers any non-POST request with 405
#    and a one-line plain-text pointer. Verified, not assumed.
#
# WHERE THIS FILE HAS TO LIVE TO DO ANYTHING.
# robots.txt is honoured ONLY at the domain root. While this tree is served from
# https://torin.bg/new/, this file is reachable but INERT -- a crawler never asks
# for /new/robots.txt. It starts working the moment the cutover promotes src/ to
# the document root. (Staging is kept out of the index by the X-Robots-Tag
# header in .htaccess, not by this file.) A green "it returns 200" check on
# staging therefore proves reachability, never effectiveness.
#
#   ##########################################################################
#   ## The sitemap directive at the end of this file is an ABSOLUTE URL, and
#   ## it is the second place in the tree that encodes the /new/ staging
#   ## segment -- site-config.php base_url is the first. At cutover BOTH
#   ## change. scripts/sitemap-check.sh asserts the two agree and fails loudly
#   ## if one is updated without the other.
#   ##
#   ## This paragraph deliberately does NOT spell the directive keyword, so
#   ## that counting it with a plain grep yields exactly one hit: the real
#   ## directive. A keyword named in prose is indistinguishable from a second
#   ## declaration to any counter, and to a hurried reader.
#   ##########################################################################
