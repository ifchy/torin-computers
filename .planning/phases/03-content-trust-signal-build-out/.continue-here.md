# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each was discovered through an actual failure in this phase.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: **Local gates cannot validate PHP on this project** — there is no local PHP
      interpreter, so a page can pass every local gate and still be broken. Structural mitigation:
      no PHP page may be recorded as working until it has been deployed to staging and fetched, and
      the fetched body checked for `<b>Warning`, `Fatal error`, `parse error` and `<?php` leakage.
      A 200 status alone proves nothing.
- [ ] CONSTRAINT: **Never give a page data array a generic `$torin_*` name** — `header.php` is
      required by every page, so anything it assigns lands in that page's global scope. Structural
      mitigation: page-specific names only (`$torin_ekran_page`, `$torin_meh_page`, …).
- [ ] CONSTRAINT: **An absent surface must force `INCONCLUSIVE`, never a pass** — `[].every()` is
      `true`, so any check over zero collected elements passes vacuously. Structural mitigation:
      collect absent surfaces into an `inconclusive` list and degrade the verdict on it.
- [ ] CONSTRAINT: **`origin/main` must be level with HEAD before dispatching any wave** — Claude
      Code's `isolation="worktree"` forks from `origin/HEAD`, and the `worktree.baseRef:"head"`
      setting is NOT honoured mid-session. Structural mitigation: `git rev-list --left-right --count
      origin/main...HEAD` must read `0 0` before every dispatch; push if not.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| PHP validated only locally | `header.php` assigned `$torin_page = basename($_SERVER['SCRIPT_NAME'])` into page global scope. Four pages had named their own data array the same thing. PHP 5.2 answers `$string['intro']` by casting the key to `0` and returning **character zero**, so every lookup returned one letter, all six `foreach` loops warned, and the pages served **HTTP 200 rendering «s»** where their prose belonged. Five plans' local gates passed on these files. | blocking | Deploy + fetch + grep the served body before recording any PHP page as working. Never accept a 200 as proof. |
| Generic global variable names | Any name a shared include assigns is squatted in the including page's global scope. | blocking | Page-specific data-array names, enforced by reading the assignment and the render call together. |
| Vacuous probe pass | `[].every()` is `true`. A first-draft probe returned PASS on a page with zero breadcrumbs by having no targets to measure. | blocking | Absent surfaces go into an `inconclusive` list and force the verdict down. |
| Stale worktree fork base | Wave 1 halted (exit 42) because the harness forked from `origin/main`, nine commits behind HEAD. | blocking | Assert `origin/main...HEAD` is `0 0` before dispatch. `git remote set-head origin -a` has been run, which fixed `origin/HEAD` resolution permanently. |
| Gate counts English comments | `smyana-na-klaviatura` passed a mechanical word gate at 918 while sitting at **595 Bulgarian words**, under the real 600 bar. | advisory | Strip `/* */` and `//`, then count only tokens matching `[а-яА-Я]`. |
| Comment quotes a gated string | `grep -c 'Защо не отлагате смяната на буксата'` returned 2 because a head comment quoted the heading. Same class recurred in 03-09's own gate. | advisory | A source comment must never quote verbatim a string that a gate greps for. |
| Broken inherited gate regexes | The short-array gate `(=>[^;]*\]\|\[\s*[^]]*=>)` fires on untouched valid PHP 5.2 and can never pass. BSD grep has no `-P`. BSD grep mishandles `$` in `grep -c 'if (!isset($torin_title))'` — use `grep -cF`. A price grep matched `EUR` inside "amat**eur**". | advisory | Use `(=>\|=)[[:space:]]*\[\|return[[:space:]]+\[`; use `LC_ALL=C grep -c '[^ -~]'`; prefer `grep -F` for literals containing `$`. |
| Counting occurrences vs distinct things | 03-08's plan asserted one `index.html#kat-` anchor, but two consumers render every category (card grid + Услуги dropdown), so each emits two. | advisory | When a gate counts matches, check whether it should count distinct values — `\| sort -u \| wc -l`. |
| zsh does not word-split | `for f in $FILES` over a space-separated string treats the whole string as ONE filename. | advisory | Use an array. |
