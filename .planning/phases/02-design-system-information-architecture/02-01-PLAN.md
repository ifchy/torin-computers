Prove the entire Phase 2 design system end-to-end on one real page, on the real host, before
any of the other fifteen pages are touched.

binary, CSS token layer, PHP utility layer, PHP shared chrome, page markup, live host — into

`bell.host.bg`. There is no local PHP (RESEARCH Pitfall 7), the host runs PHP 5.2.17, and
`woff2` MIME handling on budget shared hosting is unverified. Retiring all of that on one
page costs one commit; discovering it after sixteen pages costs the phase.

Output: a live, styled homepage hero; the three production stylesheets plus the dev-only
theme override; the rewritten shared chrome; the icon library; and a compression spike that
sets the CSS byte budget for the rest of the phase.

|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `includes/dev-switcher.php` — `?theme=` **and the `torin_theme` cookie** into the `<html>` attribute | high | mitigate | Validate **both** inputs against the hardcoded whitelist `array('a','b')` with a strict `in_array` **before** any use, then write a code-chosen literal — never the supplied value. Asserted live twice: once with a script-tag payload in the query parameter, and once with the same payload forged into the cookie, each confirming zero reflection and no theme attribute. The cookie branch is the one that persists across all sixteen pages, so leaving it untested would leave the actual production path unexercised. |
| T-02-02 | Denial of Service | `src/.htaccess` — appended `mod_deflate`/`mod_expires` directives | high | mitigate | Every optional module wrapped in its own `<IfModule>` guard (an unguarded directive for an absent module 500s the whole subtree); post-deploy assertion that the homepage still returns 200 and that `<IfModule>` open/close counts match. |
| T-02-03 | Information disclosure | `src/.htaccess` line 20 — the versioned CloudLinux PHP handler | high | mitigate | Append-only edit; byte-level assertion that `AddHandler application/x-httpd-php52 .html .htm` survives, plus a live assertion that the response contains no raw PHP opening tag. Losing this line serves the source of every include to the public. |
| T-02-04 | Spoofing | `X-Robots-Tag` on the `/new/` staging subtree | medium | mitigate | The `mod_headers` block is proven working; assert the `noindex, nofollow` header is still present on the live response after the `.htaccess` edit. The subtree must stay out of the index until the Phase 4 cutover. |
| T-02-05 | Tampering | Runtime third-party asset surface | medium | mitigate | Sofia Sans is self-hosted; no font CDN, no `ajax.googleapis.com`, no `cdnjs.cloudflare.com` reference survives. This closes the existing mixed-active-content hole where the legacy homepage loads a Modernizr script over plain HTTP on an HTTPS page. Asserted by the live vendor sweep returning 0. |
| T-02-SC | Tampering | Supply chain — the two `woff2` binaries | medium | mitigate | This phase installs **zero** package-manager dependencies (no npm, PyPI, or crates), so no legitimacy checkpoint applies. The single third-party artefact is a font binary, audited APPROVED under OFL in 02-RESEARCH §Package Legitimacy Audit and 02-UI-SPEC §Registry Safety. Integrity is established by the 02-RESEARCH V1 shaping gate, which proves the binary is the Bulgarian-letterform font rather than merely the right number of bytes; the recorded sizes 25568 / 40372 are compared and logged but are deliberately **not** a hard gate, because Google re-cuts subset binaries on upstream revision and a byte-count trip would block on a non-defect. The `fonttools`/`uharfbuzz` verification tools live in a throwaway venv and must not appear in any deliverable. |
| T-02-06 | Spoofing | FTPS transport to `bell.host.bg` | medium | mitigate | Reuse the established Phase 1 pattern: credentials base64-decoded inside a short-lived process into a chmod-600 netrc temp file consumed by `curl --netrc-file`, transport `--ftp-ssl` with the recorded public-key pin. Never echo the password; clean up on trap. |
</threat_model>

<verification>
Run in order. Every check is a shell one-liner or a documented manual step — this project has
no test runner, no build tooling, and no local PHP by constraint.

1. **02-RESEARCH V1** — font shaping gate, 15/15. Blocks all typographic work if it fails.
2. **02-RESEARCH V3** — PHP 5.2 lint across every `.php` and the homepage. All greps silent.
3. **02-RESEARCH V4** — encoding hygiene: UTF-8, no BOM, plus the live Cyrillic round-trip.
4. **02-RESEARCH V8** — compression probe. Record the result; it sets the CSS budget's status.
5. **Live tracer sweep** — 200, `lang="bg"` exactly once, charset in the first 1024 bytes, no
   raw PHP tag, zero legacy vendor references, CSS and font both 200, `X-Robots-Tag` intact.
5b. **Live empty-page sweep** — `about.html`, an untouched stub assigning nothing, still renders
   the full chrome with the default title, no PHP diagnostic text, and no empty wrapper element.
6. **Live theme flip** — default carries no theme attribute, `?theme=a` carries exactly one,
   the selection persists to a second page through the cookie, and an injection payload
   supplied in either the query parameter or the cookie reflects nothing.
6b. **Phone-scalar sweep** — no consumer of the scalar phone config value survives, which is the
   precondition plan 02-03 asserts before promoting that key to a list.
7. **Human check** — 360x640 above-the-fold and horizontal-overflow, Bulgarian letterform
   spot-check against the legacy site, throttled font-swap reflow, Theme B reviewed first.
</verification>

<success_criteria>
- The homepage at `https://torin.bg/new/index.html` renders the new design system end-to-end
  on the real host, returning 200 with parsed HTML.
- Sofia Sans is self-hosted, gate-verified to produce Bulgarian letterforms, and loads from
  the same origin with no CDN request.
- Not one reference to the legacy vendor stack survives in the homepage response.
- The dev-only theme switcher flips the palette by one attribute, reflects no input, and is
  gated by file existence so its absence in production is verifiable from a directory listing.
- The versioned PHP handler and the staging `noindex` header both survive the `.htaccess` edit.
- The three production stylesheets total under 20 KB raw, with the compression result recorded.
</success_criteria>
