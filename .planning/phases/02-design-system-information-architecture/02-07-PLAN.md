<objective>
Close the last two verified reachability and wiring gaps.

**`covid.html` is reachable from nowhere.** It returns HTTP 200 and has zero inbound links across
all sixteen deployed responses, verified by grepping every fetched page. The legacy site linked it
from the homepage, so this is a reachability regression. It is an EU-grant publicity page for project
BG16RFOP002-2.073, a category that ordinarily carries a publication obligation (Reg. EU 1303/2013
Art. 115 + Annex XII). The obligation has very likely lapsed for a 2020-era COVID measure under a
closed programme period — but the downside of being wrong is an audit finding against the company,
and **D-35 already permits a footer link**, so closing this needs no new decision and costs one
anchor.

**The homepage bypasses the single source of truth for contact values.** `index.html` hardcodes the
phone in three `tel:` hrefs and the Viber destination in three more. `footer.php` and
`category-page.php` render theirs from `site-config.php` — and in a different dial form, so one
homepage currently serves the same phone as two different strings. More consequentially, editing the
file whose header declares it the single source of truth for site-wide contact values changes the
footer and the three category pages and leaves the hero, the repeated CTA and the sticky call bar
pointing at the old number. That is precisely the "changed on sixteen pages but not the
seventeenth" failure this project's stack decision cites as the reason to abandon copy-paste HTML.

Purpose: success criterion 3 says a visitor can reach *any* part of the site. And the phase's own
key-link table records `index.html` CTAs → `site-config.php` as NOT WIRED — a broken link in the
architecture, not a style defect.

**Requirement claim, stated plainly.** This plan claims **IA-02** for the footer-reachability half of
criterion 3, delivered through the same shared footer plan 02-03 built under IA-02. The
single-sourcing repair maps to no requirement ID: it closes a row in the phase's key-link table. It
is recorded that way rather than attached to a requirement it does not genuinely serve. IA-01 and
SEO-02 are verified SATISFIED and are guarded against regression here, not claimed.

Output: `covid.html` linked from all sixteen footers, and one telephone fact with one representation
and one reader path.

**Scope fence.** WR-09 — the opening hours stored twice, in `site-config.php` and independently in
`jsonld.php` — is the same class of defect as WR-10 and lives in the same two files this plan opens.
It is deliberately **out of scope** and must not be fixed here. So are CR-03 through CR-06 and every
other warning outside WR-08 and WR-10.
</objective>
