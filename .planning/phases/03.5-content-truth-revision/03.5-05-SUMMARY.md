## Deviations from Plan

### 1. [Rule 1 — factual error] The `[ASSUMED]` marker over `warranty_key` was RETIRED, not preserved

- **Found during:** Task 2.
- **Issue:** The plan's acceptance criteria say *"Every `[ASSUMED]` marker already on the category-6

- **Fix:** Retired, with the reason written in-file, following the precedent 03.5-01 set for the
  identical case in `site-config.php`: *"gone because the question behind it was answered, not
  because a marker was tidied away."* The two genuinely open markers (#3a, #3b) survive.
- **Also:** #3b's marker text asserted the shop *"has not yet described that class at all."* D3.5-06
  means that is no longer true — the owner named it. The marker is **narrowed, not closed**: the
  assumption is now about which *work*, not which *class*.
- **Measured:** 4 `[ASSUMED]` occurrences before, 4 after — coincidence, not preservation. The
  retired one is replaced by an explanation that contains the word.

### 2. [Rule 2 — missing critical functionality] Two free-assessment promises the plan did not list

- **Found during:** Task 2, by reading the page rather than by running the gate.
- **Issue:** The plan names the intro's promise. Two more sat in `process` steps 2 and 4, and a
  third in an FAQ answer. On a category the owner carved out of that promise, each is a term a
  customer holds the shop to at the counter.
- **Fix:** All removed. Nothing stated in their place, per the same rule that governs the warranty.

### 3. [Rule 3 — plan predates a later decision] The three retired-page references

- **Found during:** Task 1, flagged in advance by the orchestrator and by 03.5-01's handoff.
- **Issue:** The plan's text predates D3.5-09 and expected the link in the `related` list. It is in a
  **block**, and there is also a **prose clause** the plan does not mention, promising the detail on

  live broken claim. The gate failure was the gate working.
- **Not filed against OWNER-QUESTIONS**, because it was resolvable honestly inside this plan's scope:
  the content had already moved onto this page, so the fix was to stop promising it elsewhere.
