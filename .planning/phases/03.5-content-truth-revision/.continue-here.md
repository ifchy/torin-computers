# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each was discovered through an actual failure in this project. Acknowledge each explicitly.

- [ ] CONSTRAINT: **A page returning HTTP 200 is not evidence it works.** No local PHP interpreter
      exists, so the live deploy is the only syntax and runtime check. The `$torin_page` global
      collision served 200 while rendering the single letter «s» where prose belonged, and passed
      every local gate across five plans. Deploy, fetch, and grep the served body for `<b>Warning`,
      `<b>Notice`, `Fatal error`, `parse error` and `<?php`.
- [ ] CONSTRAINT: **A grep proving a string is absent does not prove the page still reads well.**
      This is a subtraction phase. Cutting ~95 claims can leave pages that render, return 200, pass
      every gate — and read as though something was torn out. Verify what pages *say*, not only what
      they no longer contain.
- [ ] CONSTRAINT: **Invent nothing (CONTEXT D3.5-08).** Where a cut leaves a page thin and no honest
      content fills it, restructure or record the gap against OWNER-QUESTIONS. Never generate
      plausible-sounding replacement copy. This outranks every word-count floor in the phase — which
      is why the floors print `REPORTED, NOT GATED` rather than blocking.
- [ ] CONSTRAINT: **Reading an implementation is not measuring it.** The planner concluded the
      homepage failed `adjacentTintedPairs === 0` by reading `trust-signals.js` and the source
      section list. It was wrong — `torin_render_brand_row()` injects a section at render time. One
      `curl` would have caught it. Source and rendered are different domains; say which one you mean.
- [ ] CONSTRAINT: **No blast-radius figure may be published without its token set.** Three defensible
      token sets over the same unchanged tree return 95/11, 82/9 and 67/10. A number without its
      tokens is unreproducible, and this is the phase whose whole purpose is that published figures
      are true.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | How it manifested | Severity | Prevention |
|---|---|---|---|
| Gate that cannot fail | `gateA && gateB; VAR=$(...); test … && echo OK` — `;` ends the `&&` chain, so the shell exits with the *last* command's status and every earlier failure is discarded. Found in 6 of 7 plans. One both-directions gate passed *precisely when* its forward control failed. | blocking | Every correctness gate ends `\|\| exit 1`. Word-count floors deliberately stay advisory — hard-gating them would convert "report the shortfall" into "pad the page". |
| Success indistinguishable from silence | `truth-gate.js src/css` returning rc=0 because the directory arg was swallowed: scans nothing, exits clean, prints OK. | blocking | Assert the *expected* non-zero (`test "$RC" -eq 1`), never merely "did not crash". |
| Source/rendered domain conflation | Plan asserted `grep -c '<section' src/index.html` = 6, a source grep against a rendered count. They differ by exactly one, always, because the brand row is a PHP include with no `<section` literal. | blocking | Label every assertion `SOURCE:` or `RENDERED:`. Never satisfy one by editing toward the other. |
| Cross-worktree dependency in a wave | Plan 04 gated on `grep -ro … src/` being 0, but the references live in `index.html`, owned by a *sibling* plan in the same wave, in a separate worktree. Would have failed deterministically. | blocking | Wave-local gates check only files the plan owns; tree-wide assertions move to the post-merge audit plan. |
| String-deleting a surviving capability | «ниво чип» labels work category 4 *keeps* (power circuits, individual components) on `problem-stari.html`. A blind removal pass would have destroyed it. | blocking | Read the surrounding claim before removing a token. Correct the vocabulary; don't excise the content. |
| Evidence strips vanish silently | `torin_render_evidence()` (`category-page.php:265`) emits nothing when a photo file is absent — withdrawing the three reballing photos shortens or empties strips at HTTP 200, no error. | advisory | Check the *rendered* strip, never the source. |
| Broken inherited gates | Short-array regex fires on valid PHP 5.2; word gates count English comments (inflate ~50%); BSD grep has no `-P` and mishandles `$`; zsh does not word-split unquoted expansions; `grep -c` counts lines not occurrences. | advisory | Use `(=>\|=)[[:space:]]*\[\|return[[:space:]]+\[`; count `[а-яА-Я]` tokens; `grep -F`, `LC_ALL=C grep -c '[^ -~]'`; arrays; `grep -o … \| wc -l`. |

<context>
The through-line of this project is that automated gates keep passing on things that are broken, and
the discipline that has saved it every time is refusing to record an unrun or unmeasured check as
passing. That discipline caught the `$torin_page` collision at deploy rather than at cutover, kept
Category 6 honest-but-thin instead of plausible-but-fabricated, and in this session caught a
fabricated defect that was about to be published in the audit of the phase whose entire purpose is
that published figures are true.

Phase 3.5 is that discipline applied to the site's claims rather than its code. The work is
subtraction, and the risk is not that too much gets cut — it is that something gets cut carelessly
and a page is left hollow, or that a cut is faked with invented filler. Both failure modes are
gated. Trust the gates only as far as constraint 1 allows.
</context>
