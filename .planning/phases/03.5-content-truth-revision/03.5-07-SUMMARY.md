## 🔴 The open defect

`src/remont-na-portove.html:103` publishes:

> «Резултатът в такива случаи е частична или пълна повреда на **южния мост**, а **единственото
> решение тогава е подмяна на самия чип**.»

Replacing a southbridge is a BGA operation — discontinued under **D3.5-01**. This is not a symptom,
a cause or a diagnostic observation. It names a remedy, as *the only one*. It is **the only
surviving chip-replacement claim in the tree**.

**Three failures lined up to hide it:**

1. `truth-gate.js` carries `southbridge` as the base literal «южен мост»; every occurrence in the
   tree is declined («южни**я** мост»). `grep -rnoiE 'южен мост|северен мост' src/` returns
   **nothing** — those two literals have never matched anything and cannot, as written.
2. **No content plan owned the file.** `git log 98994e3..HEAD -- src/remont-na-portove.html` is
   empty.
3. It has **zero typed inbound links** — reachable only through the `kat-2` hub's `parent`-filter
   loop.

**The same sentence shape on a page that had an owner was corrected.** 03.5-06 rewrote
`mehanichni-problemi.html:111` — «пиновете… влизат директно в южния мост» → «управляващия чип на
платката». The difference in outcome is ownership, not difficulty.

**Not fixed here, deliberately.** The plan is explicit that a fix found at audit time belongs in a
gap-closure plan with its own gate, not in a commit that also claims the audit passed. The fix is a
**vocabulary correction, not an excision** — the surrounding safety argument (a wobbly port carries
the fault inward; do not defer it) is true and must survive.

## The blast-radius reconciliation — all three figures reproduce EXACTLY

CONTEXT said there is no single true count and that three defensible token sets return 95/11, 82/9
and 67/10. **The reconciliation is now complete, and the missing ingredient was not the token set —
it was the method.**

| Token set | Command | Result | Claimed |
|---|---|---|---|
| SET-57 | `grep -roiE 'BGA\|реболинг\|ребол\|чипсет\|видеочип\|инфрачервен\|AMTECH\|дозапояване\|северен мост\|южен мост' --include='*.html'` @ `98994e3` | **57 in 9 files** | 57/9 ✅ |
| SET-95 | SET-57 **+** `\|ниво чип\|регенерац`, same command | **95 in 11 files** | 95/11 ✅ |
| Gate | `node scripts/truth-gate.js` @ `98994e3` | **165 in 21 files**, 42 scanned | — |

**Neither historical figure was ever wrong.** 57 → 95 is the token set (adding «ниво чип» and the
regeneration stems; the consequential miss was `problem-stari.html`, which carries 20 «ниво чип» and
**none** of SET-57's tokens). 95 → 165 is token set *plus* scope (the gate adds retired filenames,
excluded brands and the semantic free-diagnostics matcher, and scans `includes/` and `css/` too).

### The finding that generalises the phase's own rule

**With the token set held exactly constant, method alone moves SET-95 across a 51% spread:**

| Method | Result |
|---|---|
| occurrences, **case-insensitive** | **95** ← the published figure |
| occurrences, case-sensitive | 83 |
| lines matched (`grep -c`) | 63 |
| per-token sum | 87 |

**Three method traps were hit while writing this audit**, each caught by re-measurement: case
folding on the blast radius (83 vs 95), case folding again on the «първоначалн» count (13 vs 26),
and comment inclusion on the `torin_service_href(` assertion (6 vs 5). A fourth appeared in the
Cyrillic word counts, where `[а-яА-Я][а-яА-Я-]*` and `[а-яА-Я]+` return 233 and 235 on the same file.

**Recommended amendment:** a figure must carry its token set **and the exact command**. The command
carries the method implicitly — which is why `truth-gate.js` printing its own token set on every run
is the right pattern and a prose citation is not.
