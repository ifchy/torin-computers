## 🔴 The open defect — now live

`src/remont-na-portove.html:103` publishes:

> «Резултатът в такива случаи е частична или пълна повреда на **южния мост**, а **единственото
> решение тогава е подмяна на самия чип**.»

```bash
$ curl -s https://torin.bg/new/remont-na-portove.html \
    | grep -oiE 'южни[ця][^ ]* мост|северни[ця][^ ]* мост' | wc -l

```

Replacing a southbridge is a BGA operation — discontinued under **D3.5-01**. This is not a symptom,
a cause or a diagnostic observation. It names a remedy, as *the only one*. It is **the only
surviving chip-replacement claim in the tree**, and it is **being served**.

**Three failures lined up to hide it:**

1. `truth-gate.js` carries `southbridge` as the base literal «южен мост»; every occurrence in the
   tree is declined («южни**я** мост»). `grep -rnoiE 'южен мост|северен мост' src/` returns
   **nothing** — those two literals have never matched anything and cannot, as written.
2. **No content plan owned the file.** `git log 98994e3..HEAD -- src/remont-na-portove.html` is
   empty.
3. It has **zero typed inbound links** — reachable only through the `kat-2` hub's `parent`-filter
   loop.

**The same sentence shape on a page that had an owner was corrected.** 03.5-06 rewrote
`mehanichni-problemi.html:111` — «пиновете… влизат директно в южния мост» → «управляващия чип на
платката». The difference in outcome is ownership, not difficulty.

**Not fixed here, deliberately.** A fix found at audit time belongs in a gap-closure plan with its
own gate, not in a commit that also claims the audit passed. The fix is a **vocabulary correction,
not an excision** — the surrounding safety argument (a wobbly port carries the fault inward; do not
defer it) is true and must survive.
