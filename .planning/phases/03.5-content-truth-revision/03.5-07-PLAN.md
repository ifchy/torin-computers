<objective>
Prove the phase, tree-wide and live, and write down what is true and what is not.

Six plans have each gated their own files. That is necessary and it is not sufficient, for three
reasons this project has already paid for:

1. **Nothing has run PHP yet.** There is no local interpreter. Every plan before this one recorded
   its live checks as NOT RUN, correctly. The deploy in this plan is the first and only time the
   phase's PHP is executed, and a page returning 200 proves nothing on its own — the `$torin_page`
   collision served 200 on four pages while rendering the single letter «s» where prose belonged,
   and passed every local gate across five plans.
2. **Per-file gates cannot see a cross-file gap.** A link removed in one plan and a symptom line
   written in another can disagree, and neither plan's gate would notice.
3. **Evidence strips fail silently.** `torin_render_evidence()` emits nothing when a referenced
   photograph is absent on the server. Three photographs were withdrawn this phase. A strip that
   vanished returns HTTP 200 with no error anywhere, and only a count taken from the **served body**
   catches it.

This plan carries every requirement ID in the phase because it is the only place any of them is
proven rather than implemented.

Purpose: convert six plans' worth of local confidence into one set of live measurements.
Output: `03.5-TRUTH-AUDIT.md` — the phase's evidence record, including everything that did not pass.
</objective>
