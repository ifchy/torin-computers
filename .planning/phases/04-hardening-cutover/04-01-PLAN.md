<objective>
Replace every host unknown this phase is gated on with one measurement, then move
`public_html/new/` off PHP 5.2.17 without serving a single page of raw source.

Purpose: RESEARCH §Environment Availability marks six dependencies as "probe" — GD, EXIF,
curl, outbound 443, local MTA, and the raised upload limits — and every one of them decides
the shape of a later plan. There is no local PHP interpreter on this project (a structural
property, not a gap), so the deploy is the only PHP check that exists. This plan is the
phase's environment gate: nothing downstream may be written against an assumption this
plan could have measured.

Output: `04-HOST-CAPABILITIES.md` (the measured record), a repaired handler block in
`src/.htaccess`, and 19 pages still executing on a modern PHP.

**Relation to the phase tracer (TRACER_MODE=true):** this plan is the phase's *environment
gate*, deliberately sequenced ahead of the tracer. It contains no `type="tracer"` task because
its probe file is throwaway by contract (deployed by explicit path, read once, deleted, asserted
404) and a tracer is production code you write for keeps. **The phase tracer is 04-02** — one
enquiry wired end to end through every layer. RESEARCH §Summary is explicit that the tracer
cannot be written before this plan runs: the notification channel, the upload limits and the mail
transport are all decided by facts only the probe can produce, and this project has paid twice
for assuming host behaviour instead of measuring it.

**Decisions implemented (locked in CONTEXT.md):** D4-01 (upgrade the runtime first), D4-02 (test the handler on the staging subtree only), D4-03 (an account-wide switch cannot break the current live site — verified, not assumed), D4-04 (watch for the panel rewriting the handler block), D4-06 (probe outbound HTTPS before committing to the notification channel), and the measurement half of D4-13 (the upload limits are read here and raised in 04-03).
</objective>
