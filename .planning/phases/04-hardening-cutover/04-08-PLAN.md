  <action>
    Raise the stylesheet and script lifetimes from minutes to one year in the expiry block, inside
    the existing module guard, as its own clearly delimited concern with a one-line statement of
    what breaks if it is wrong. The current short values exist only because this subtree was a
    staging preview being reviewed daily, and the file says so — replace that rationale, do not
    leave it standing beside a contradictory value.

    A one-year lifetime is safe **only** because every first-party asset URL already carries a
    modification stamp that changes when the file does. State that dependency in the block itself.
    Anything not stamped may not take the long lifetime.

    **Exception one: the Cyrillic web font stays unstamped and keeps its existing lifetime.**
    Stamping it would break the byte match with its own font-face rule, downloading the subset twice
    on every cold visit — and it would blind the font-swap measurement, whose fallback pass blocks by
    a filename glob that stops matching the moment a query string is appended. A stamped font does
    not fail that check, it makes it report a flawless result while measuring nothing, which is worse
    than a failure.

    **Exception two: HTML stays short, and the contact page carries an explicit no-store exclusion.**
    The page sets that header itself in PHP, but the expiry rule for HTML must carry the exception
    **explicitly rather than by accident**, because the failure mode is the form rejecting real
    people: a cached contact page hands every visitor the same signed render timestamp, so either
    the accept window has to be so wide it is useless or genuine submissions get refused.

    Re-measure afterwards and record the wire figures, not the disk figures. This project's earlier
    assumption that the origin serves no compression is false — it returns compressed responses for
    markup, stylesheets and scripts, which is why the budget is stated in wire bytes and why the
    design-reasoning comments in the stylesheets cost visitors approximately nothing and are not to
    be stripped.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet -> `robots.txt` / `sitemap.xml` | Both are deliberately public and enumerate the site's URL surface. Anything listed is an invitation to crawl. |
| Apache cache directives -> every response | One directive block governs how long anything is held anywhere between the origin and the visitor. |
| dev machine converter -> committed binary assets | New binary files enter the repository and the document root. |
